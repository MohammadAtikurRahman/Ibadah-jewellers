# Ibadahe Jewellery

A single-page jewellery storefront made with Bootstrap 5.3.3 and vanilla JavaScript.

## Open the shop

Open `index.html` directly in a browser, or serve the project directory using any static web host. There is no build step and no package installation.

Bootstrap is the only stylesheet. The site uses `text-primary-emphasis` and Bootstrap utility classes throughout; it has no custom stylesheet or inline CSS. All seven photographs are embedded in the HTML. Internet access is needed for the Bootstrap CDN files.

## Included

- Responsive single-page layout with full-bleed product photography.
- Product search, category filters, sorting and product details.
- Shopping bag with quantity controls, local persistence and delivery totals.
- Demo checkout; no payment gateway or order backend is connected.
- Contact: info@ibadahejewellery.com
- Address: Mirpur 1

Edit the `products` array near the end of `index.html` to change the sample catalogue. Prices are in BDT and product specifications are illustrative.
